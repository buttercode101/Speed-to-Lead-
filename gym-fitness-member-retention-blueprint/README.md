# Expanded Gym / Fitness Studio Automation Blueprint (Member Retention Engine)

A production-ready WhatsApp-first automation blueprint for South African gyms and fitness studios.

## Core Value Proposition
Automate onboarding, attendance follow-up, payment reminders, churn reduction, and owner reporting to create predictable monthly revenue.

## Primary Outcomes
- Better member retention
- Faster failed-payment recovery
- Consistent class attendance follow-up
- Reactivation of churned members
- Daily/weekly owner visibility on WhatsApp

## Free-Tier Structure (2 Scenarios)
1. WhatsApp AI Member Agent (Main Brain)
2. Retention & Reporting Engine (Scheduled)

## SA Pricing Guidance
- Starter (<=150 members): R4,500-R7,500 build + R1,000-R2,000/month
- Growth (150-400 members): R8,000-R12,000 build + R2,000-R3,000/month
