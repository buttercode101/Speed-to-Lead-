# Lead Status Playbook

## Status definitions
- **New**: Lead captured, no human contact yet.
- **Contacted**: First human outreach attempted.
- **Qualified**: Need, budget, timeline, and service fit confirmed.
- **Quoted**: Price estimate/scope sent.
- **Closed**: Job won/booked.
- **Lost**: Lead not won (reason required).

## Required actions by status
### New
- Call within SLA.
- Send acknowledgement if not already sent.
- Set follow-up due.

### Contacted
- Log method (call/WhatsApp/email).
- Record outcome (reached/no answer).
- If no answer, schedule next follow-up.

### Qualified
- Capture service scope, location, budget band, urgency.
- Assign owner.
- Set quote deadline.

### Quoted
- Record quote value/date.
- Schedule quote follow-up in 24h.

### Closed
- Record job value and close date.
- Tag source for reporting.

### Lost
- Select loss reason (no budget, no answer, competitor, out of area, other).
- Add improvement note.

## Daily operating cadence
- 09:00: Review all New/Contacted leads > 12h
- 13:00: Midday follow-up sweep
- 17:00: End-of-day unresolved leads review
