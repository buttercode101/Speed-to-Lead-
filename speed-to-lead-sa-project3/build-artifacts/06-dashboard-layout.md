# 1-Page Dashboard Layout Spec

## Header KPIs
- New leads (this week)
- Median first-response minutes
- Contact rate
- Close rate
- Revenue won (ZAR)

## Visual blocks
1. **Lead Aging Funnel**
   - 0–5 min
   - 5–30 min
   - 30+ min
   - 24h+
2. **Pipeline by Status**
   - New / Contacted / Qualified / Quoted / Closed / Lost
3. **Trend (last 8 weeks)**
   - Leads
   - Contact rate
   - Close rate
4. **Escalation Heatmap**
   - By day/time block
5. **Loss Reason Breakdown**

## Action panel
- Top 3 bottlenecks
- Owners with overdue follow-ups
- Next-week improvement actions
