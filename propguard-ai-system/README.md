# PropGuard AI System (South African Property Management Automation)

PropGuard AI System is a WhatsApp-first, integrated automation suite for property managers and landlords managing 10–300+ units.

## Core Value Proposition
Automate tenant communication, rent collection, maintenance workflows, document handling, owner reporting, and reactivation in one cohesive system.

## Included Workflows
1. WhatsApp AI Tenant Agent (Speed-to-Lead + Support)
2. Automated Rent Collection & Reminders
3. Maintenance Request Handler
4. Document Processing (leases, invoices, supplier bills)
5. Follow-up & Nurture Sequences (new tenants & prospects)
6. Database Reactivation (past tenants & landlords)
7. Internal Reporting & Owner Alerts (Daily/Weekly BI)

## Architecture (Free-Tier Optimized)
Start with 2 active scenarios:
- Scenario 1: WhatsApp AI Central Brain
- Scenario 2: Scheduled Automations (Daily/Weekly)

## Data Hub
Use one Google Sheet: `PropGuard Master Hub` with tabs:
- Properties
- Tenants
- Rent & Payments
- Maintenance
- Owners
- Leads & Prospects
- Old Database
- Documents
- Reports Log

## Pricing Guidance (SA)
- Starter (<=30 units): R6,500 setup + R1,200/month
- Growth (31–100 units): R9,500–12,000 setup + R1,800–2,500/month
- Enterprise (100+ units): R15,000+ setup + R3,000+/month
