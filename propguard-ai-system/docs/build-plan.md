# Build Plan - PropGuard AI System

## Goal
Deploy a single integrated automation package for SA property managers that improves rent collection, cuts response delays, and creates visibility for owners.

## Phase 1 (Day 1): Core Live System
- Create PropGuard Master Hub sheet
- Build Scenario 1 (WhatsApp AI Central Brain)
- Build Scenario 2 (Scheduled Automations)
- Test core rent + maintenance + owner alert flows

## Phase 2 (Day 2-3): Reliability & Refinement
- Tune intent routes
- Tune reminder timing tiers (pre-due/due/overdue)
- Add exception escalations
- Add summary reporting logs

## Phase 3 (Week 2): Expansion
- Reactivation campaigns in monthly batches
- Document extraction improvements
- Deeper owner analytics and unit-level metrics

## Success Metrics
- <5 minute initial response time via WhatsApp
- Increased on-time rent payments
- Faster maintenance acknowledgment
- Daily/weekly owner reports delivered automatically
