# Go-Live Checklist

## Pre-go-live
- [ ] Intake form tested with real phone formats
- [ ] Sheet schema matches template exactly
- [ ] Data validation applied to Status
- [ ] Owner alert email received under 60 seconds
- [ ] Auto acknowledgement content approved by client
- [ ] Escalation contacts configured (primary + backup)
- [ ] Error route tested with forced failure

## Go-live day
- [ ] Submit 3 live test leads (normal, urgent, duplicate)
- [ ] Verify all rows logged correctly
- [ ] Verify escalation does not trigger for contacted lead
- [ ] Verify escalation triggers for untouched test lead

## First 7 days
- [ ] Daily heartbeat message received
- [ ] No unresolved automation errors
- [ ] Weekly KPI report delivered
- [ ] Client signs operational acceptance
