# Build Plan - Follow-up & Nurture Sequences

## Why this is second
- Immediate ROI from improved response consistency.
- Built on existing Sheets + WhatsApp + status foundations.
- Low operational overhead and easy client value demonstration.

## Phase 1 (Core Sequences)
### Deliverables
- Scheduled follow-up engine (weekday 09:00 and 14:00)
- Multi-stage sequence routing (Day 1, Day 3, Day 7, Final)
- CRM updates on every follow-up send

### Success Criteria
- Only leads with active sequence and due date are contacted.
- Follow-up count increments correctly.
- Next follow-up date is calculated and stored.

## Phase 2 (Reply Detection)
### Deliverables
- Detect incoming WhatsApp replies
- Stop sequence immediately
- Mark lead as replied
- Notify owner to follow up ASAP

### Success Criteria
- Sequence Active flips to NO on reply.
- Replied flips to YES on reply.
- Last Reply Date is set on every inbound message.

## Optional Phase 3 (AI Enhancements)
- Personalize follow-up tone by service context
- Sentiment labels (interested/confused/price-sensitive)
- Daily owner digest summary
