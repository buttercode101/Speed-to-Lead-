# Medical & Dental Clinic Automation Blueprint (Appointment Guardian System)

A complete WhatsApp-first automation blueprint for South African clinics: medical, dental, physio, and veterinary.

## Core Value Proposition
Reduce no-shows, improve booking speed, automate reminders, simplify admin, and deliver daily operational visibility.

## Main Outcomes
- Faster lead and patient response
- No-show reduction with reminder cadence
- Better billing reminder recovery
- Automated daily owner/manager reporting
- Lower admin workload

## Free-Tier Structure (2 Scenarios)
1. WhatsApp AI Patient Agent (Speed-to-Lead + Support)
2. Automated Reminders + Daily Operations

## Pricing Guidance (SA)
- Build: R6,000-R11,000 one-time
- Retainer: R1,500-R3,200/month
