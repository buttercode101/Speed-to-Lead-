# WhatsApp AI Tenant Agent Blueprint (Speed-to-Lead + Ongoing Support)

This blueprint is the core conversational engine for South African property management operations.

## Package Positioning
A 24/7 WhatsApp-first AI assistant for tenants and landlords that handles:
- Rent inquiries and payment guidance
- Maintenance requests and ticket acknowledgements
- Lease/general support questions
- New viewing/prospect requests
- Complaint escalation and human handoff

## Core Benefits
- Instant tenant response anytime
- Better tenant communication consistency
- Lower office call volume
- Faster maintenance intake and tracking
- Improved collection follow-through

## Pricing Guidance (SA)
- Setup: R4,500 – R8,500
- Monitoring/Support: R1,000 – R2,200 per month
