# Real Estate Agent WhatsApp AI Agent Blueprint (SA, 2026)

A production-ready, WhatsApp-first automation blueprint for South African real estate agencies.

## What this solves
- Slow lead response times
- Unqualified inquiry overload
- Missed viewing opportunities
- Weak follow-up consistency
- Poor pipeline visibility

## Core outcomes
- Instant lead qualification via WhatsApp
- Property matching from Listings sheet
- Viewing booking with Google Calendar
- Automated follow-ups for stalled leads
- Daily pipeline updates in Google Sheets

## Free Tier Architecture (2 Scenarios Max)
1. Main WhatsApp AI Agent (Core Intelligence)
2. Follow-up & Pipeline Maintenance (Scheduled)

## SA pricing guidance
- Setup: R4,000 – R8,500
- Monthly monitoring/tweaks: R900 – R2,200
